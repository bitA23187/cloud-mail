# Wiki Schema

## Scope

`wiki/` is the stable knowledge layer for `cloud-mail`. It is for reusable project understanding, not for source code or secret material.

## Page Types

- `architecture`
- `decision`
- `feature`
- `runbook`
- `incident`

## Conventions

- Keep pages short and practical.
- Use lower-case hyphenated filenames.
- Prefer one topic per page.
- Update `index.md` when adding or materially changing a page.
- Append notable actions to `log.md`.

## Exclusions

Do not store secrets, tokens, `.env` values, or other credential-bearing content in `wiki/`.
